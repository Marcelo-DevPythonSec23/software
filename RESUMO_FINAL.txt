```bash
cd /home/dev_marcelo/projetos/software
.venv/bin/pip install -r requirements.txt
```

### 2️⃣ Rodar API (2 min)
```bash
cd software
export PYTHONPATH=sorce
.venv/bin/uvicorn forensic_cti.api:app --reload
```
→ http://localhost:5000/docs

## 💡 EXEMPLOS RÁPIDOS

### Ingestão
```bash
curl -X POST "http://localhost:5000/ingest/file?path=/tmp/events.csv"
```

### Buscar IOC
```bash
curl "http://localhost:5000/events/search?ioc=192.168.1.100"
```

### Correlacionar
```bash
curl "http://localhost:5000/correlation/ip?time_window=3600"
```

### Treinar ML
```bash
curl -X POST "http://localhost:5000/ml/train?limit=500"
```

### Gerar Relatório
```python
from forensic_cti.reports import ReportGenerator

report = ReportGenerator("Meu Relatório")
report.add_finding("Descoberta", "Descrição", severity="high")
report.add_ioc("192.168.1.100", "ip", "high", "Fonte")
report.save_html("relatorio.html")
```
